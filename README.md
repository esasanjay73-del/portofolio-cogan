# Portofolio Esa Sanjaya

Website portofolio statis (HTML + CSS + JavaScript), tanpa build step.

## Struktur
```
index.html          halaman utama
css/style.css       seluruh gaya
js/script.js        animasi, mode pixel, musik latar
assets/images/      semua foto
music/starboy.mp3   (tambahkan sendiri) musik latar
```

## Hosting di GitHub Pages
1. Buat repository baru di GitHub, lalu unggah **isi** folder ini (bukan folder induknya) sehingga `index.html` ada di root repo.
2. Buka **Settings → Pages**.
3. Pada *Build and deployment*, pilih **Deploy from a branch**, branch `main`, folder `/ (root)`, lalu Save.
4. Tunggu 1-2 menit; situs tersedia di `https://<username>.github.io/<nama-repo>/`.

Catatan: nama file di GitHub Pages peka huruf besar/kecil. Pastikan `music/starboy.mp3` ditulis persis seperti itu.
